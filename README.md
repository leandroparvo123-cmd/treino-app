# Caderno de Treino

App de treino (personal + tela de treino do aluno), publicado no Netlify e com dados no Firebase.

- `index.html`, `app.js`: o app
- `fig.js`: boneco anatômico animado e biblioteca de exercícios
- `config.js`: configuração do projeto Firebase
- `firestore.rules`: regras de acesso do banco (colar no console do Firebase)
- `seed.js`: treinos iniciais de um caderno novo

O Netlify publica automaticamente cada mudança na branch `main`.
